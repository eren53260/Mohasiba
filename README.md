
# دفتر قرض — نسخه 1

برنامه آفلاین فارسی برای ثبت و محاسبه قرض‌ها.

## امکانات
- ثبت قرض داده‌شده یا گرفته‌شده
- نام شخص، مبلغ، تاریخ و توضیحات
- ثبت پرداخت‌های جزئی
- محاسبه خودکار مانده
- جستجو
- ویرایش و حذف
- ذخیره آفلاین روی گوشی
- پشتیبان‌گیری و بازیابی JSON
- رابط فارسی و راست‌چین

## ساخت APK بدون Android Studio
این پروژه برای GitHub Actions آماده شده است.

1. فایل ZIP را استخراج کنید.
2. یک Repository جدید در GitHub بسازید.
3. تمام فایل‌های پروژه را در Repository قرار دهید.
4. به بخش **Actions** بروید.
5. Workflow با نام **Build Android APK** را اجرا کنید.
6. پس از پایان، در بخش Artifacts فایل APK را دریافت کنید.

همچنین می‌توان پروژه Flutter را به سرویس‌های Build آنلاین مانند Codemagic متصل کرد.

## اجرای محلی
اگر Flutter نصب باشد:
```bash
flutter pub get
flutter build apk --release
```

فایل نهایی معمولاً در:
`build/app/outputs/flutter-apk/app-release.apk`
قرار می‌گیرد.
